# Lesson 04 — Reflection

## 1. Technical Reflection

**What was the most difficult Python concept you learned in Lesson 4, and why?**

The most difficult concept for me was understanding the structure of conditional statements, especially when working with multiple conditions.

I had to learn how to properly use parentheses to group conditions together and make sure Python evaluates the logic correctly.

Through practice, I became more comfortable using `and`, `or`, and `not` to build conditional statements.

## 2. Cybersecurity Reflection

**How could the SOC Alert Triage Tool help a security analyst during an investigation?**

The SOC Alert Triage Tool can help a security analyst determine the priority of an alert based on information collected during an investigation.

Using conditional statements, the tool evaluates information such as risk scores, failed login attempts, malware detection, and network connections.

Input validation helps prevent invalid information from being processed. Based on the conditions that are met, the tool assigns an alert classification and recommends an appropriate action.

This demonstrates how Python can be used to support security alert triage and automate repetitive decisions.

## 3. Personal Growth Reflection

**Compared to when you started learning Python, what do you feel more confident doing now?**

I feel much more confident writing Python code independently.
